# Credit Risk Analyzer

Interactive Streamlit interface for the Credit Risk Project notebook. It uses a calibrated XGBoost classification pipeline to estimate an applicant's probability of loan default.

## Project files

- `app.py` — interactive applicant form and risk results.
- `train_model.py` — trains and saves the calibrated XGBoost pipeline and decision threshold.
- `requirements.txt` — Python dependencies.
- `render.yaml` — Render web-service configuration.

## 1. Prepare the model locally

Place the original `credit_risk_dataset.csv` in this project folder. The CSV should contain the columns used in the notebook:

`person_age`, `person_income`, `person_home_ownership`, `person_emp_length`, `loan_intent`, `loan_grade`, `loan_amnt`, `loan_int_rate`, `loan_status`, `loan_percent_income`, `cb_person_default_on_file`, `cb_person_cred_hist_length`.

Then run:

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
python train_model.py
```

This creates:
- `credit_risk_model.pkl`
- `best_threshold.pkl`

The training script follows the notebook's data cleaning, preprocessing, selected XGBoost hyperparameters, sigmoid calibration, and F1-based threshold selection.

## 2. Run the app locally

```bash
streamlit run app.py
```

## 3. Deploy on Render

1. Push this project folder to a GitHub repository.
2. Make sure `app.py`, `requirements.txt`, `render.yaml`, `credit_risk_model.pkl`, and `best_threshold.pkl` are in the repository root.
3. In Render, choose **New + → Blueprint** and connect the repository. Render reads `render.yaml`.
4. Deploy the service and open the generated `onrender.com` URL.

### Important model-file note

The `.pkl` files are generated by `train_model.py`; they are not included in this starter bundle because the notebook upload did not include the dataset or trained model artifacts. Generate them before deployment. For a public repository, avoid committing private or sensitive training data. If model files are too large for Git, store them using an appropriate artifact or object-storage service and configure `MODEL_PATH` and `THRESHOLD_PATH` environment variables.

## Model interpretation

The output is a model-estimated probability of default. The app compares it with the saved threshold to show a higher-risk or lower-risk classification. This is a decision-support demonstration, not a lending recommendation or guarantee.
